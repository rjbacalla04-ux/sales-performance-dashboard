# Sales Performance Dashboard

## Project Overview

This project analyzes sales performance using PostgreSQL and Power BI.

The goal is to identify:

- Sales trends
- Profitability
- Customer performance
- Target achievement

---

## Tools Used

- PostgreSQL
- Power BI
- Excel

---

## Skills Demonstrated

- Data Cleaning
- SQL Queries
- Data Analysis
- Data Visualization
- KPI Reporting
- Business Insights

## Key Metrics

- Total Sales: 431.5K
- Total Profit: 23.9K
- Total Orders: 500
- Total Quantity Sold: 5,615

---

## Key Insights

- Top-performing customers contributed significantly to overall revenue.
- Several products generated sales but negatively affected profit.
- Monthly sales performance fluctuated throughout the year.
- Sales target achievement varied across months.
